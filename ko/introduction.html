소개 ​

lognal은 터미널처럼 보이고 터미널처럼 동작하는 웹 페이지용 로그 뷰어입니다. 로그를 캔버스에 그리기 때문에 메시지가 빠르게 쏟아지거나 기록이 길게 쌓여도 페이지가 느려지지 않습니다.

할 수 있는 일 ​

  • 콘솔 출력 옮겨 보기. console.log, console.warn, console.table, console.group 같은 콘솔 메서드 호출을 기록하고, 브라우저 개발자 도구와 같은 모습으로 보여 줍니다. 원래 콘솔도 그대로 동작합니다. 콘솔 기록을 참고하세요.
  • 값을 타입에 맞게 표시. 객체, 배열, Map, Set, 오류, DOM 요소를 로그를 남긴 순간의 모습으로 저장하고, 클릭해서 펼치거나 접습니다. 값 표시를 참고하세요.
  • 텍스트 파일 읽기. 로그 파일을 조각으로 나눠 읽고, 인코딩을 알아내고, ANSI 이스케이프 코드를 색으로 바꿉니다. Chromium 계열 브라우저에서는 계속 늘어나는 파일도 따라 읽습니다. 텍스트 파일을 참고하세요.
  • 로그 뷰어다운 기능. 도구 모음에서 새 로그 따라가기, 로그 지우기, 맨 위나 맨 아래로 이동, 줄 바꿈 켜고 끄기, 텍스트와 수준으로 거르기를 할 수 있습니다. Ctrl+F로 로그를 검색하면 아무것도 숨기지 않고 일치하는 곳을 모두 강조합니다. 상태 표시줄은 항목 수를 보여 주고, 항목마다 타임스탬프를 붙일 수 있으며, 텍스트를 선택해서 복사하거나 항목 메뉴에서 항목 하나를 통째로 복사할 수 있습니다. 로그 안의 주소는 새 탭에서 열리는 링크가 되며, 기본으로는 열기 전에 한 번 묻습니다. 항목 모드에서는 파일을 고르듯 Ctrl, Cmd, Shift로 항목을 통째로 골라 한꺼번에 복사할 수 있습니다. 뷰어를 참고하세요.
  • 명령 입력. 입력 줄을 켜면 입력한 명령을 직접 만든 함수에 넘기고 그 응답을 출력합니다. 입력 줄을 참고하세요.
  • 테마 맞추기. 밝은 테마, 어두운 테마, 자동 모드를 기본으로 제공하고, 모든 색을 CSS 사용자 지정 속성으로 바꿀 수 있습니다. 테마와 글꼴을 참고하세요.
  • 한국어와 CJK 문자 처리. 전각 문자는 두 칸을 차지하고, 줄이 바뀔 때 한글 낱말은 쪼개지지 않으며, 입력 줄은 IME 조합과 함께 동작하고, EUC-KR 같은 레거시 인코딩도 알아냅니다. 한국어와 CJK 문자를 참고하세요.

캔버스에 그리는 이유 ​

줄마다 DOM 요소를 하나씩 만드는 로그 뷰어는 기록이 늘어날수록 느려집니다. 요소 하나하나가 메모리와 스타일 계산, 레이아웃 작업을 차지하므로, 화면에는 40줄만 보여도 10만 줄짜리 목록은 무거운 페이지가 됩니다.

lognal은 항목을 순수한 데이터로 보관하고 화면에 보이는 행만 그립니다. 작업은 세 부분으로 나뉩니다.

  1. LogStore가 항목을 추가된 순서대로 보관합니다. 기본 한도는 10,000개이고, 한도를 넘으면 가장 오래된 항목부터 버립니다.
  2. LogLayout이 현재 너비에 맞춰 항목을 행으로 나눕니다. 측정한 줄을 캐시에 두므로 대부분의 프레임은 앞서 한 계산을 다시 씁니다.
  3. 렌더러가 보이는 행을 <canvas>의 2D 컨텍스트로 그립니다. 두 애니메이션 프레임 사이에 새 메시지가 몇 개 들어오든 그리기는 한 번입니다.

그래서 한 프레임을 그리는 비용은 쌓인 기록의 양이 아니라 화면에 보이는 행 수로 정해집니다.

브라우저가 캔버스보다 잘하는 일은 여전히 브라우저가 맡습니다. 로그 영역은 브라우저의 스크롤 컨테이너라서 마우스 휠, 터치, 키보드 스크롤이 평소처럼 동작합니다. 입력 줄은 실제 <textarea>여서 캐럿, 붙여넣기, IME 조합을 브라우저가 처리합니다. 도구 모음은 실제 버튼으로 이루어져 있고, 화면에 보이지 않는 목록이 보이는 항목을 스크린 리더에 전달합니다.

캔버스에 그린 텍스트는 페이지 텍스트에 포함되지 않습니다. 대신 뷰어가 선택, 복사, 필터를 직접 제공합니다. 드래그해서 선택하고, Ctrl+C나 Cmd+C로 복사하고, 도구 모음의 필터로 찾으면 됩니다. 텍스트를 칸 단위 격자에 배치하므로 로그 영역에는 고정폭 글꼴이 필요합니다.

패키지 구성 ​

lognal은 진입점이 세 개인 npm 패키지 하나입니다. 코어는 런타임 의존성이 없습니다. React는 선택적 피어 의존성이며 lognal/react를 쓸 때만 필요합니다.

브라우저 지원 ​

lognal은 Chrome, Edge, Firefox, Safari의 최신 버전을 대상으로 합니다. 패키지는 ES2022로 컴파일합니다. 일부 기능은 비교적 새로운 브라우저 API에 기댑니다.

  • 그래핌 클러스터. lognal은 Intl.Segmenter로 텍스트를 사용자가 인식하는 글자 단위로 나눕니다. Chrome 87, Firefox 125, Safari 14.1부터 쓸 수 있습니다. 이 API가 없으면 내장된 대체 구현이 결합 문자, 이형 선택자, 이모지 수식자, 폭 없는 결합자 시퀀스, 국기 쌍을 앞 글자에 붙입니다. setGraphemeSplitter로 직접 만든 분할 함수를 쓸 수도 있습니다.
  • 파일 따라 읽기. followTextFile에는 File System Access API(showOpenFilePicker)의 파일 핸들이 필요합니다. 이 API는 Chromium 계열 브라우저에만 있고, HTTPS나 localhost로 연 보안 페이지에서만 동작합니다. readTextFile은 모든 브라우저에서 동작합니다.
  • 복사. copySelection은 보안 페이지에서는 비동기 Clipboard API를 쓰고, 그 밖의 환경에서는 document.execCommand('copy')로 대신합니다.
  • Safari의 IME 입력. Safari 26까지는 조합을 끝내는 키의 keydown보다 compositionend가 먼저 발생합니다. 입력 줄은 이 순서를 고려하므로, 일본어나 중국어 후보를 확정하려고 Enter를 눌러도 명령이 제출되지 않습니다.
